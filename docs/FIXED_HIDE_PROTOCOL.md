# Fixed-hide checkpoint comparison, protocol 1

Production base58c54a0; no production tuning. Before confirmation outcomes, freeze
this protocol and study sources in Git. Pilot572900 (one root) is excluded.

Run32 fresh root journeys: seeds572000-572003, April/May, no livestock/two goats,
free/hired artisan. Reuse the released crew income strategy, skills, contracts,
65% aim, normal pace and skilled survival decisions. No new money or supplies.
Four worlds repeat across strata; these are not32 independent worlds.

At the first real stopped state with a prepared deer hide and artisan2 currently
able to dress it, capture the full actual save plus hunting-aim RNG and policy
counters. Capture occurs after an ordinary hunt/recovery, never by adding a hide.
Roots without such a state are reported as no opportunity, not omitted silently.

Restore two independent production engines from that identical save. Test-only
observers copy all production script variables from the validated restore and
must recapture exactly the same save. Regression coverage compares their next day
with the plain production restore. No mutable state is shared between branches.

Both continuations start with exactly the same existing skins. Base finish_hunt
selects no new pelts; record and require zero subsequent pelt harvest in both arms.
All original survival hunting, fishing, forage, food, weather, wages, animal care,
medical and travel rules continue normally through public actions.

Crew continuation may sell existing skins. Craft continuation follows the previous
crafting policy: reserve one input pipeline when cash>=2 and a meal remains;
assign a qualified unreserved helper after higher-priority chores; no dedicated
craft-only rest. Keep the same paid-work/sale rules. This tests the fixed-batch
policy including retention/unfinished-work risk, not guaranteed perfect crafting.
No strategy changes after confirmation data are opened.

Continue both branches to arrival/loss/day365 under existing action/stall/save
checks. Report matched outcomes, original travelers present, elapsed days and
actual post-fork meals/shortages; income by type, contracts, craft stages, material
loss/unfinished stock, and actual sales. Conditional shared-arrival timing is
secondary. No-opportunity roots are a separate denominator. Do not pool this
conditional checkpoint sample with the prior whole-trip 96-case campaign.

Freeze source/rules hashes, refuse overwrite, archive raw reports/checkpoints and
receipts with SHA-256. Publish compact per-root/per-branch results and verifier.
No historical wage, tariff or yield revision is inferred by this test alone.
