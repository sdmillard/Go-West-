# Seasonal-fish validation protocol

Freeze final runtime/data/GDScript before campaigns. Do not tune profiles to held-out results. All previous fishing audit cohorts stay archived and separate; no species profile is a promised cash/food buff.

- Run test.ps1: 76 suites, including seasonal pools, zero seasonal salmon weights, size/edible bounds, ordinary rounding, mixed fractional catches, observer parity and genuine previous-save preservation.
- Run 24 store + 20 current-policy outlaw integrations. Compare journey rows to the preceding unchanged-policy reports; they should remain identical when nobody fishes.
- New fish rules: 144 journeys, three existing fishing-audit strategies (off/leader/support), three professions, May/July, four seeds per phase. Development 255000-255003; held-out 265000-265003. Shared horse/tack, standard outfit, steady pace and 65% scripted bite reactions. Existing policy logic remains unchanged.
- Generic-fish old-game controls: 48 support-policy journeys at previous commit 546489f, same worlds/carts/costs. Keep their different source/rules fingerprints separate. Compare policy file hashes explicitly.
- Repeat 1,800 actual one-day controlled trips with the existing 225000-225099 probe seeds, 0/4/12 road miles, three rations, healthy/poor leader and five present travelers. The prior generic 1,800-trip report is a separate old-rule comparison, not pooled evidence.
- Verify actual generated units from settlement, rather than reconstructing new zero-unit small catches using the historical minimum-one rule. Retain fractional leader/worker mass in all observers.
- Check actual named-catch popup, setup species list and landing animation natively. No new art.
- Preserve full reports/logs in parent .tools and hash-check copies against isolated originals before cleanup. Compact summaries record source/rules/settings, complete declared cohorts and identical starts.

Do not claim farmer balance is solved from small cohorts. Only compare completion time for paired arrivals; fewer days before a death are not faster travel. Results measure one scripted strategy family, not every possible crew assignment or human response.
