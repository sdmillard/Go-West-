## 2. Wiring `ui/hunt_view.gd` (Hunting Mini-Game)

Replace the blocky `draw_rect` animal, cover, and hunter drawing in `ui/hunt_view.gd` with the new sprite sheets while keeping all aiming, hitboxes (`target_rect(index)`), and muzzle-flash lines identical:

```gdscript
const PRAIRIE = preload("res://art/pixels/prairie.png")
const BISON = preload("res://art/pixels/hunt_bison.png")
const DEER = preload("res://art/pixels/hunt_deer.png")
const RABBIT = preload("res://art/pixels/hunt_rabbit.png")
const COVER = preload("res://art/pixels/hunt_cover.png")
const HUNTER = preload("res://art/pixels/hunt_hunter.png")
```

Inside `_draw()` of `ui/hunt_view.gd`:
1. **Animals (`for index in range(encounter.animals.size()):`):**
   - Keep the existing `if encounter.animals[index].direction < 0:` horizontal flip `draw_set_transform(...)`.
   - Select the texture by `kind`:
     ```gdscript
     var tex: Texture2D = [BISON, DEER, RABBIT][kind]
     var frame: int = int(encounter.elapsed * 8.0 + index) % 2
     var fw := int(bounds.size.x)
     var fh := int(bounds.size.y)
     draw_texture_rect_region(tex, Rect2(p, bounds.size), Rect2(frame * fw, 0, fw, fh))
     draw_set_transform(Vector2.ZERO)
     ```
2. **Foreground Cover (`for obstacle in encounter.cover:`):**
   - Use frame `0` for `"woodland"` / `"forest"` and frame `1` for open prairie / sagebrush / highcountry:
     ```gdscript
     var cover_frame := 0 if encounter.region in ["woodland", "forest"] else 1
     draw_texture_rect_region(COVER, obstacle, Rect2(cover_frame * 12, 0, 12, 14))
     ```
3. **Hunter & Rifle:**
   - Draw `HUNTER` centered on `hunter`:
     ```gdscript
     var hunter: Vector2 = encounter.hunter.round()
     draw_texture(HUNTER, hunter - Vector2(8, 17))
     var direction: Vector2 = (get_local_mouse_position() - hunter).normalized()
     draw_line(hunter + Vector2(0, -7), hunter + Vector2(0, -7) + direction * 12, Color("302b2c"), 2)
     if encounter.flash > 0:
         draw_line(hunter + Vector2(0, -7), encounter.aim, Color("f6e7bc"), 1)
     ```


In `center_text(text: String, y: int)` and `_draw()`:
1. Add a 1px chiseled light relief behind each line of carved text so it looks incised into the limestone:
   ```gdscript
   func center_text(text: String, y: int) -> void:
       draw_string(FONT, Vector2(123, y + 1), text, HORIZONTAL_ALIGNMENT_CENTER, 188, 8, Color("f6e7bc"))
       draw_string(FONT, Vector2(122, y), text, HORIZONTAL_ALIGNMENT_CENTER, 188, 8, Color("45372f"))
   ```
2. In `_draw()`:
   ```gdscript
   func _draw() -> void:
       draw_texture(GRAVESTONE_FRAME, Vector2.ZERO)
       if record.is_empty():
           return
       var companion: bool = record.get("kind", "party") == "companion"
       center_text("HERE LIES" if companion else "HERE REST THE PARTY OF", 38)
       center_text(str(record.name).to_upper(), 50)
       center_text(("DIED " if companion else "") + str(record.date), 63)
       center_text("GUIDE MILE %d" % record.miles, 75)
       draw_rect(Rect2(140, 81, 152, 1), Color("8a5e3e"))
       draw_rect(Rect2(140, 82, 152, 1), Color("f6e7bc"))
       # Keep the existing word-wrap loop for `record.epitaph` at y = 94 + index * 10
   ```
